# Тесты NBrain

Тесты не обращаются к OpenAI: запросы эмбеддингов подменяются детерминированной
заглушкой, поэтому запуск бесплатный и работает без интернета. Каждый тест
создаёт свою временную базу и не трогает `data/`: `test_traversal.py` для этого
копирует `server.py`, `web/` и `requirements.txt` во временный каталог и
поднимает сервер уже на копии. Раньше он писал заметку-маркер в настоящую базу.

```powershell
cd nbrain_mvp
python tests/test_nbrain.py      # логика: аккаунты, векторы, EPUB, поиск, изоляция данных
python tests/test_http.py        # сквозной прогон через реальный HTTP-сервер
python tests/test_traversal.py   # проверка обхода каталога без авторизации
```

Каждый файл возвращает код выхода 1, если хоть одна проверка провалилась.

## Что покрыто

**test_nbrain.py** (205 проверок)

- создание первого аккаунта, хранение пароля хешем, вход с кириллическим
  паролем, отказ на подделанной подписи, истёкшем сроке и cookie неизвестного
  аккаунта;
- правила логинов и паролей, отказ на занятом логине, смена пароля закрывает
  сессии только своего аккаунта, защита последнего администратора;
- изоляция аккаунтов: список книг, поиск, overview, переиндексация, удаление,
  заметки, действия, профиль и каталог развития у каждого свои; подставленный
  чужой `book_id` ничего не находит; удаление аккаунта уносит его книги,
  фрагменты, файлы и профиль, не задевая чужие данные;
- троттлинг входа: бесплатные попытки, растущая задержка, блокировка, изоляция по IP;
- упаковка векторов в float32, нормализация, совпадение результатов numpy и
  чистого Python, отказ при несовпадении размерности;
- чтение EPUB строго по `spine`: порядок глав 1–2–10, исключение оглавления и
  обложки, запасной путь для EPUB без spine;
- фоновая индексация, содержимое таблицы `chunks`, поиск и сортировка оценок;
- Thinker и deep-разбор тратят ровно один запрос эмбеддинга;
- переиндексация после смены модели, удаление книги с каскадом и файлом;
- понятные тексты ошибок для пустой библиотеки, failed-книги и устаревшего индекса;
- сопоставление каталога с загруженными книгами без ложных срабатываний;
- разбор `Content-Length`: мусор, пустая строка, отрицательное значение и
  превышение лимита дают `ClientError`, а не `int()`-исключение;
- защита от ZIP-бомб: EPUB, распаковывающийся сверх лимита, и архив со
  слишком большим числом элементов отклоняются, обычный EPUB читается как раньше;
- очередь индексации ограничена: при переполнении новая книга получает
  `ClientError`, после освобождения снова принимается;
- таблица попыток входа не растёт без предела и чистится от устаревших записей;
- регистрация: адрес приводится к нижнему регистру, логин выводится из адреса,
  повторная регистрация отвечает так же и не создаёт второй аккаунт и не меняет
  пароль первого, некорректные адреса и короткие пароли отклоняются;
- письма: ссылка подтверждения одноразовая, истёкшая не срабатывает, выдача
  новой гасит предыдущую, токен хранится только хешем, запрос сброса для
  несуществующего адреса не отправляет письмо;
- анкета: несуществующие интересы и пустые цели отбрасываются, «Название —
  Автор» разбирается на две части, границы времени и формата дат проверяются,
  повторное сохранение заменяет ответы, анкеты аккаунтов не пересекаются;
- экспорт своих данных без пароля и без чужих записей, удаление своего аккаунта
  с проверкой пароля и каскадной очисткой анкеты, целей и токенов;
- квоты: превышение даёт понятную ошибку со временем ожидания, соседний клиент
  не затронут; лимиты длины вопроса и числа выбранных книг;
- проверка конфигурации при старте: анонимный режим запрещён на публичном
  адресе, короткий секрет сессии отклоняется;
- резервная копия содержит те же аккаунты и книги, что и живая база.

**test_http.py** (99 проверок)

- миграция базы старого формата (`embedding_json`) на блобы с проверкой значений;
- реальные HTTP-запросы: вход, 401 без сессии, `202` на загрузку, опрос статуса,
  поиск, ответ, переиндексация, удаление, `400` вместо `500` на кривом вводе,
  `429` при подборе пароля;
- вход одним паролем по-прежнему открывает основной аккаунт, логин
  нечувствителен к регистру, ответ не подсказывает, существует ли логин, и не
  содержит хеша пароля;
- второй аккаунт по HTTP: своя пустая библиотека, чужой `book_id` даёт `400`,
  чужие заметки не видны, `/api/users` закрыт для неадминистратора (`403`),
  смена своего пароля сбрасывает cookie тем же ответом, а cookie удалённого
  аккаунта перестаёт работать;
- подменённый `X-Forwarded-For` не снимает блокировку и не плодит записи, но за
  доверенным прокси заголовок по-прежнему различает клиентов;
- некорректный `Content-Length` (`abc`, `-1`, пустой) даёт `400`, а не `500`;
- запрос с чужого `Origin` отклоняется, со своего проходит, JSON без
  `Content-Type: application/json` не принимается;
- заголовки безопасности: CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`;
- регистрация, вход по почте, анкета через HTTP, пустая библиотека у нового
  аккаунта, журнал писем закрыт от обычного пользователя и открыт админу,
  подтверждение адреса по ссылке, страница `/verify` отдаётся браузеру;
- экспорт отдаётся файлом и не содержит пароля, удаление своего аккаунта
  сбрасывает cookie тем же ответом и делает сессию недействительной;
- исчерпание квоты поиска отвечает понятной ошибкой.

**test_traversal.py** (5 проверок)

  На исходной версии четыре из них отдавали `server.py` и файл базы данных.
