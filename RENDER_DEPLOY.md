# Публикация NBrain на Render и домене nbrain-ts.org

Этот способ делает NBrain доступным по защищённому адресу
`https://app.nbrain-ts.org` с компьютера и телефона. Каждый читатель заводит
собственный аккаунт и заполняет профиль сам: чужих данных в новом аккаунте нет.

## Перед началом

Нужны два аккаунта:

1. GitHub — для безопасного хранения исходного кода NBrain.
2. Render — для запуска приложения в облаке.

Не добавляйте API-ключ OpenAI, пароль или секрет сессии в GitHub и не
отправляйте их в чат. Они вводятся только в защищённых переменных Render.

## 1. Загрузить код в GitHub

1. Создайте на GitHub новый **private**-репозиторий, например `nbrain`.
2. Загрузите в него папку проекта `nbrain_mvp`.
3. Убедитесь, что файл `.env` не попал в репозиторий. В нём не должно быть
   ключей или паролей.

## 2. Создать веб-сервис в Render

1. Откройте `https://dashboard.render.com/` и войдите через GitHub.
2. Выберите **New → Web Service** и подключите репозиторий `nbrain`.
3. В поле **Root Directory** укажите `nbrain_mvp`, если эта папка находится
   внутри репозитория. Если в репозитории сразу лежат `server.py` и
   `Dockerfile`, оставьте поле пустым.
4. В качестве окружения выберите **Docker**.
5. Задайте имя сервиса, например `nbrain`.
6. В разделе Health Check Path укажите `/api/health`.

## 3. Добавить защищённые переменные Render

В разделе **Environment** добавьте:

| Переменная | Значение |
|---|---|
| `OPENAI_API_KEY` | ваш новый действующий ключ OpenAI |
| `ANTHROPIC_API_KEY` | необязательно: ключ Anthropic API для режима Claude |
| `NBRAIN_AUTH_REQUIRED` | `1` |
| `NBRAIN_ADMIN_USERNAME` | логин первого аккаунта латиницей, например `admin` |
| `NBRAIN_ADMIN_DISPLAY_NAME` | имя, которое видно в интерфейсе, например `Цэцэглэн` |
| `NBRAIN_ADMIN_PASSWORD` | отдельный длинный пароль для входа в NBrain |
| `NBRAIN_SESSION_SECRET` | длинная случайная строка, не менее 32 символов |
| `NBRAIN_SECURE_COOKIES` | `1` |
| `NBRAIN_DATA_DIR` | `/app/data` |
| `NBRAIN_PUBLIC_URL` | `https://app.nbrain-ts.org` |
| `NBRAIN_TRUST_FORWARDED_FOR` | `1` |

Не создавайте переменную `PORT`: её выдаёт Render автоматически.

`NBRAIN_TRUST_FORWARDED_FOR=1` нужен именно на Render. Снаружи до сервиса можно
достучаться только через прокси платформы, поэтому заголовку `X-Forwarded-For`
здесь можно доверять. Без него все посетители считаются одним клиентом: один
человек, подбирающий пароль, заблокирует вход всем остальным.

`NBRAIN_ADMIN_USERNAME` и `NBRAIN_ADMIN_PASSWORD` используются один раз — при
создании первого аккаунта на пустой базе. Дальше аккаунты живут в базе, пароли
меняются в интерфейсе, а новые пользователи регистрируются сами.

### Письма: подтверждение адреса и восстановление пароля

Пока эти переменные не заданы, письма не отправляются: NBrain пишет их в журнал
сервиса, и администратор выдаёт ссылку вручную. Регистрация и вход при этом
работают.

| Переменная | Значение |
|---|---|
| `NBRAIN_SMTP_HOST` | адрес SMTP-сервера, например `smtp.gmail.com` |
| `NBRAIN_SMTP_PORT` | `587` для STARTTLS, `465` для SSL |
| `NBRAIN_SMTP_USER` | логин почтового ящика |
| `NBRAIN_SMTP_PASSWORD` | пароль приложения, а не основной пароль почты |
| `NBRAIN_SMTP_FROM` | адрес отправителя, например `NBrain <nbrain@nbrain-ts.org>` |
| `NBRAIN_SMTP_SECURITY` | `starttls`, `ssl` или `none` |

### Резервное копирование

Persistent Disk — не резервная копия. Раз в неделю выполняйте в Render Shell:

```bash
python server.py backup
```

Команда кладёт согласованную копию базы в `/app/data/backups/`. Скачивайте её
вместе с папкой `/app/data/uploads`, где лежат исходные файлы книг.

## 4. Подключить постоянное хранилище

Книги, индекс и профиль хранятся в папке `/app/data`. В Render создайте
**Persistent Disk** и подключите его к сервису по пути `/app/data`.
Без диска данные могут исчезнуть после обновления или перезапуска сервиса.

## 5. Подключить домен

1. После первого успешного запуска в Render откройте **Settings → Custom Domains**.
2. Добавьте `app.nbrain-ts.org`.
3. Render покажет точную DNS-запись (обычно CNAME).
4. В Cloudflare откройте домен `nbrain-ts.org` → **DNS → Add record** и
   добавьте запись точно так, как её показывает Render.
5. Дождитесь проверки домена и выпуска HTTPS-сертификата в Render.

Не создавайте DNS-запись заранее: используйте значение, которое выдаст
Render для вашего сервиса.

## 6. Финальная проверка

Откройте `https://app.nbrain-ts.org`, войдите по паролю NBrain, загрузите
небольшую книгу и задайте вопрос. В ответе должны появиться ссылки на
источники. После этого NBrain можно открывать из любого современного
браузера, включая телефон.

## Важно

Persistent Disk у Render предоставляется на платном типе веб-сервиса.
Это необходимо для безопасного сохранения загруженных книг и базы NBrain.
